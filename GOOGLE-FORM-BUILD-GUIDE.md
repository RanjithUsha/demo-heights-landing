# Build your client Google Form (15 minutes)

Open **https://forms.google.com** → **+ Blank**. Follow this file **top to bottom**.

---

## Form settings (do once at the start)

1. Click **Settings** (gear).
2. **Responses** → turn on **Collect email addresses** (recommended).
3. **Responses** → **Limit to 1 response** → Off (clients may need to resubmit).
4. **Make this a quiz** → Off.

After you add the **first File upload** question, Google will ask for a **Drive folder** — create: `Website Clients - Uploads` → Continue.

**File uploads:** Respondents must **sign in with Google**. Tell clients this in the form description.

## After building — link Sheet & theme

1. **Responses** tab → **Link to Sheets** → Create spreadsheet `Client Website Responses`.
2. **Customize theme** → pick your brand color (optional).
3. **Send** → copy **link** → shorten for WhatsApp if needed.

## If client cannot use Google login for uploads

Use **Tally.so** (free): same questions, enable file upload without Google sign-in, or ask them to WhatsApp a Drive/Dropbox link in Q53.
