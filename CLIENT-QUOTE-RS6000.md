### 2. Deliverables included in ₹6,000

1. **One responsive landing page** with sections aligned to industry standard project microsites:
   - Hero (project name, location, starting price, key points)
   - Overview & highlights
   - Area & pricing (configuration cards)
   - Master plan & floor plan section (images; plan requests via enquire flow)
   - Amenities
   - Photo gallery
   - Location advantages (tabbed lists; map optional if client provides embed link)
   - FAQ
   - About developer
   - Footer: RERA registration, marketing disclaimer, Privacy Policy link

2. **Lead capture**
   - Enquire **popup** (full name, email, 10-digit mobile, consent checkbox)
   - On submit: opens **WhatsApp** to client’s number with visitor details in the message
   - Sticky **Call** and **WhatsApp** actions (desktop + mobile)

3. **Legal / trust pages**
   - Dedicated **Privacy Policy** page (draft provided; final text subject to client approval)
   - Footer disclaimer and RERA block using **client-supplied and approved** wording

4. **Technical delivery**
   - Deployment to live **HTTPS** URL
   - Basic browser/mobile testing before handover
   - **One round** of content/correction revisions after first live preview (not unlimited new features)

5. **Handover**
   - Live URL shared with client
   - Source code available on request (zip or repository access as agreed)
   - Short note on how future text/image updates are done
